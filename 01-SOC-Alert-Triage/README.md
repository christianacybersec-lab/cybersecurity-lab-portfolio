# Lab 001: SOC Alert Triage and Investigation

**Date:** October 19, 2026  
**Platform:** TryHackMe  
**Environment:** SOC Simulator  
**Category:** Security Operations / Incident Investigation

## Objective

Gain practical experience investigating security alerts, identifying malicious activity, distinguishing true positives from false positives, and documenting security incidents.

## Scenario Overview

Investigated four security alerts involving potentially malicious emails and firewall activity within a simulated SOC environment.

The alerts included:
- Inbound emails containing suspicious external links
- Access to a blacklisted external URL blocked by a firewall

## Investigation Process

1. Reviewed security alerts presented in the SOC Simulator.
2. Examined available information to determine whether activity was suspicious.
3. Classified alerts as true positives or false positives.
4. Submitted investigation reports and recommended actions.
5. Reviewed simulator feedback to identify opportunities for improvement.

## Skills Practiced

- Security alert triage
- Phishing identification
- Firewall event investigation
- True positive and false positive classification
- Basic incident reporting

## Lessons Learned

I successfully identified the malicious and benign alerts but recognized that I need additional practice communicating investigation findings.

The simulator feedback highlighted the importance of identifying affected entities, documenting the sources of suspicious activity, and recommending specific remediation steps.

## Next Steps

- Improve the structure and technical detail of incident reports.
- Practice identifying related entities such as IP addresses, usernames, domains, and hostnames.
- Continue investigating simulated security alerts.
- Develop familiarity with SIEM tools and security logs.
